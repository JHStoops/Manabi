# @manabi/importers

Converts open dictionary and corpus data into Manabi content packs (see `content/`).
Importers write pack files only; they never touch progress tables.

Planned importers:

- KANJIDIC2
- JMdict
- KanjiVG
- Tatoeba
- JLPT level lists (tanos.co.uk)

Licences of each source must be recorded in `content/<pack>/AUTHORING.md`.
